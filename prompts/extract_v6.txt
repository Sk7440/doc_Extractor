<task>
Extract invoice data for an accounting system. Every value must be exact, because it is saved without a human checking it.
</task>

<steps>
1. Read the invoice inside the <invoice> tags.
2. Find these four fields:
   - invoice_number: the invoice's ID
   - date: the date the invoice was issued
   - vendor: the company that sent the invoice and is being paid
   - total: the amount to be paid
3. Convert the date and total using the rules inside the <rules> tags.
4. Return the result in the format inside the <output_format> tags. The <examples> show complete inputs and the exact outputs expected.
</steps>

<rules>
<invoice_number>
- Labels like "Invoice", "Invoice No.", "Invoice ID", "INV", "Bill", "Bill No." mark an invoice number.
- Order numbers, PO numbers and reference numbers are NOT invoice numbers. If only those appear, use null.
- Do not include the "#" symbol.
</invoice_number>

<date>
- Always write it as DD-MM-YYYY, whatever format the invoice uses.
- If a date is ambiguous, read it as day first.
- If there are several dates (issue date, due date, delivery date), use the date the invoice was issued, never the due date.
Examples:
- "2025/03/09"   -> "09-03-2025"
- "July 4, 2021" -> "04-07-2021"
- "14-MAR-2023"  -> "14-03-2023"
- "03-04-2022"   -> "03-04-2022"  (3 April, day first)
</date>

<vendor>
- The company that sent the invoice, not the customer. Ignore names after "Bill to", "Ship to" or "Customer".
- Copy the name exactly as written, without quotes.
</vendor>

<total>
- A plain number only. No currency (Rs., PKR, $, USD, EUR), no commas, not in quotes.
- If there is a subtotal, tax and a grand total, use the grand total (the final amount payable).
- Convert k, lakh, crore and words into the full number: k = 1,000; lakh = 100,000; crore = 10,000,000; hazar = 1,000.
Examples:
- "Rs. 3.5 lakh"          -> 350000
- "Rs. 2.4 crore"         -> 24000000
- "8k USD"                -> 8000
- "Seventy Five Thousand" -> 75000
- "Rs. 2,40,000"          -> 240000
- "$1,250.75"             -> 1250.75
</total>

<missing_fields>
If a field is not in the invoice, use null. Never guess or make up a value.
</missing_fields>
</rules>

<output_format>
Return only a JSON object with the keys invoice_number, date, vendor and total. No explanation, no code fences.
</output_format>
